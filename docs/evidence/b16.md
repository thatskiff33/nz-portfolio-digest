# Quality sweep B16

Finding IDs: QS-057, QS-058, QS-059, QS-060, QS-061, QS-062, QS-063.

Trade and snapshot forms retain submitted values after validation errors. Field
messages are linked to controls and an alert summary. Authenticated stale-CSRF
submissions return the populated form with a current token and no write.
Handled error pages include the authenticated sidebar and status-specific titles.

Boosted requests replace a page wrapper, leaving the status and alert regions
mounted. Navigation focuses the main content and announces the new title.
Trade save and import undo show a one-shot message after the redirect.
Comparison results are announced again on repeated submissions. Server and
network failures show visible alerts while preserving the current form.
Every full-page template has its own title.

Selected portfolios and navigation links have aria-current="page", bold text
and a four-pixel border. Edited dates select Custom; changing only the period
dropdown applies that named range. Report tables use scoped headers and row
labels, numeric total cells and readable text. Year-end tables retain their
headers and table display on narrow screens, scrolling inside their containers.

## Browser evidence

Chrome Headless Shell with Playwright, using the synthetic SQLite dashboard
fixture and report fixtures:

- Navigated between portfolios and forms using boosted links; confirmed main
  focus, the new title announcement and exactly one permanent status region.
- Submitted NaN as quantity; confirmed retained entries, linked help and field
  error, alert summary and main focus after the 400 response.
- Replaced the CSRF token with a stale value and resubmitted; confirmed the
  expired-form message and retained quantity. Submitted the refreshed form
  successfully and confirmed the trade-save announcement.
- Submitted the same matching snapshot twice; confirmed the status text was
  updated each time.
- Intercepted a comparison request with HTTP 503, then aborted its network
  request; confirmed visible alerts and retained snapshot text.
- Used browser back navigation with the HTMX history cache disabled; confirmed
  focus and title feedback after restoration.
- Undid an import and confirmed the success announcement; navigated away and
  back and confirmed it was consumed.
- Checked light and dark control-border computed colours. At 390 CSS pixels,
  there was no dashboard page overflow. This also exercises the layout width
  of a 780-pixel browser window at 200% zoom; native browser zoom and assistive
  technology speech output were not independently tested.
- Checked all seven digest data tables at narrow width: computed text size
  12px and native table display. Checked both year-end tables: 14px text,
  visible table-header groups, scrolling containers and no page overflow.
- No dashboard JavaScript errors or CSP violations were observed.
